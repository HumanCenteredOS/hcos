# ❤️ HCOS™
## Human-Centered Operating Systems™

**Healthy people create healthier systems.**

**Healthier systems help people flourish.**

HCOS™ (Human-Centered Operating Systems™) is a human-centered framework and AI-powered decision intelligence platform that helps people better understand themselves, one another, and the systems they live within.

By integrating systems thinking, human-centered design, responsible artificial intelligence, and practical implementation, HCOS™ helps organizations improve decision-making, reduce unnecessary human burden, and create healthier people, healthier organizations, and healthier communities.

# 🌍 Our Purpose

Every conversation, every decision, and every system shapes the human experience.

HCOS™ exists to help people:

## Development and Releases




HCOS™ is a living standards framework that evolves through continuous review and improvement.

All standards, prompts, instruments, examples, and supporting documentation follow the HCOS Release Process:

> **Develop → Review → Commit → CHANGELOG → Git Tag → Release**

The complete process, including versioning, review expectations, changelog requirements, Git tagging, and release guidance, is documented in:

➡️ **[RELEASE_PROCESS.md](RELEASE_PROCESS.md)**

This process helps preserve transparency, accountability, and traceability as the HCOS framework evolves.
